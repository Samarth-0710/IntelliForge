# IntelliForge Backend

AI-powered Security Operations Center (SOC) backend built with FastAPI.

## Features

- JWT Authentication
- Incident Management
- Log Analysis
- AI Threat Detection
- Dashboard Analytics
- Notifications
- PDF & CSV Reports

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Gemini AI
- JWT Authentication

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
uvicorn app.main:app --reload
```

API Docs

```
http://localhost:8000/docs
```
